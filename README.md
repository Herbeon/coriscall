# cori's call
A visual novel about Cori, a delivery guy who receives a prank call. because surely nobody is serious when they order food delivery at 4:33 am, right?

# how I made this
I first thought of this mini vn idea in April 2026, and intended to finish that month. I didn't end up finishing in april because I procrastinated lol. I used renpy for the coding, and Krita to make the art. When I'm done with it I'll use itch.io to publish! No AI was used!

# how to play
web playable will be available on itch.io! Not mobile friendly unfortunately.

# cool features/intended cool features
I wanted to try to do some more technical things in this vn!
* randomized menu options (makes playthroughs more different)
* click-to-travel gameplay (sometimes)
* interactive ending screen (trust)
