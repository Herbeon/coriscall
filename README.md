# cori's call
A visual novel about Cori, a delivery guy who receives a prank call. because surely nobody is serious when they order food delivery at 4:33 am, right?

# how I made this
I first thought of this mini vn idea in April. I used renpy for the coding, and Krita to make the art. When I'm done with it I'll use itch.io to publish!

# how to play
web playable will be available on itch.io!
